# موقع سيزر كافيه ومطعم

- `index.html`: الموقع. منيو على عمود ثري دي، بحث، سلة، وطلب بيتبعت على واتساب.
- `admin.html`: لوحة التحكم، وبتفتح على `/admin`.
- المنيو ورقم واتساب الطلبات والعنوان والمواعيد متخزنين في Supabase، والموقع بيقراهم أول ما يفتح.

## التشغيل لأول مرة

1. **اعمل مشروع على Supabase.**
2. **الجداول:** من SQL Editor شغّل `supabase/schema.sql`، وبعده `supabase/seed.sql` (ده بينقل المنيو الحالي كله، 425 صنف).
3. **حساب الأدمن:** من Authentication > Users > Add user > Create new user: الإيميل `admin@caesar.local`، وباسورد قوي، وعلّم Auto Confirm User. الحساب بيبقى أدمن لوحده، وبتدخل لوحة التحكم باسم المستخدم `admin`.
4. **الربط:** `config.js` متربط خلاص بمشروع Caesar cafe.
5. **ارفع على GitHub واربطه بـ Vercel.** الإعدادات جاهزة في `vercel.json`.
6. **افتح `/admin`، وادخل، وحط رقم واتساب الطلبات** من تبويب «الطلبات وبيانات المطعم».

## ملاحظات
- المفتاح anon معمول عشان يبقى في الموقع. الصلاحيات محمية جوه قاعدة البيانات: أي حد يقدر يقرا المنيو، والأدمن بس يقدر يعدّل.
- `index.html` جواه نسخة ثابتة من المنيو (من `src/menu.txt`) بتظهر لحظة قبل ما البيانات توصل من Supabase، أو لو Supabase مش متاح. لو عايز تحدّثها: `npm run build`.
- عايز تقفل التسجيل؟ من Authentication > Providers > Email اقفل «Allow new users to sign up». الأدمن بيتعمل يدوي من الداشبورد.

## الـ 3D
- **الهيرو:** اللوجو معمول ميدالية دهب 3D بـ Three.js. التمثال بارز، والإضاءة بتمشي مع الماوس أو ميلان الموبايل، وتقدر تلفها بالسحب. حواليها إكليل غار ودهب طاير.
- الكود في `src/hero3d.js`، والنسخة الجاهزة في `vendor/hero3d.js`. لو عدّلت فيه: `npm install` وبعدين `npm run build:3d`.
- بيتحمّل بعد ما الصفحة تفتح، فمش بيبطّأ المنيو. على الأجهزة اللي مفيهاش WebGL، أو اللي مفعّل فيها «تقليل الحركة» أو «توفير البيانات»، بيفضل اللوجو العادي.
- **أسطوانة الأقسام:** إضاءة دهبي على الوش اللي قدام، لون إضاءة مختلف لكل جناح، سحب بقوة دفع، وميلان للكارت مع الماوس.
- **السلة:** عملة دهب بتطير للسلة مع كل إضافة.
- `npm run build` بيسحب المنيو والإعدادات من Supabase وقت النشر على Vercel، فالصفحة بتفتح بآخر بيانات على طول.
